# CBC with TTA Methods

- Dataset/setting: CIFAR-10-C severity 5, corruption-wise evaluation.
- Compared methods: CLIP original, 9 raw TTA methods, and each TTA method with CBC calibration.
- TTA methods: clipartt, unient, stamp, tda, adacontrast, watt, watt_otsu, watt_unient, etta.
- Files: `tta_corruption_s5_long_19methods.csv`, `tta_corruption_s5_wide_19methods.csv`, `tta_overall_summary_19methods.csv`, `tta_overall_long_19methods.csv`.
